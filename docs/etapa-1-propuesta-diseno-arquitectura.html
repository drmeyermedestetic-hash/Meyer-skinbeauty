03

Tipografía

Combinación editorial + clínica, tal como en el mockup aprobado.

Display / Editorial — títulos, hero, campañas
Skincare, Beauty & Science
Propuesta: Cormorant Garamond o Playfair Display (Google Fonts) — serif alta, elegante, la misma familia visual del cartel "MEYER".
Sans / Funcional — precios, botones, filtros, checkout
AGREGAR AL CARRITO — $ 32.900
Propuesta: Inter o Helvetica Neue — limpia, moderna, para toda la interfaz transaccional.

09

Wireframes — referencia por pantalla

Home mobile: header sticky → hero con foto real del local → categorías circulares → destacados → banner Science Meets Skin (fondo negro) → novedades → The Meyer Edit → beneficios → Instagram → footer. (ver mockup, pantalla 1)
Producto mobile: galería táctil (PNG + ficha) → marca/nombre/precio → selector cantidad → agregar al carrito (negro) / comprar ahora (champagne) → acordeones de información. (pantallas 3–4)
Carrito: drawer lateral con items, cantidad editable, subtotal/envío/descuento/total, finalizar compra. (pantalla 5)
Checkout: datos de envío → medio de pago (Mercado Pago) → resumen del pedido → confirmación con número de pedido. (pantallas 6–8)
Desktop: mismo sistema de diseño, header horizontal con todas las categorías visibles, grilla de 4 productos por fila. (ver mockup desktop, sección 04)
